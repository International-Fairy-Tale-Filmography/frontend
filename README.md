# IFTF Data Editor

The data editor provides table-style access to the IFTF filmography data.

## Editing data

- Choose a data set at the top of the editor, then select a table to browse or edit records.
- **Save changes** keeps your edits in the current tab. The editor keeps a recovery copy in this browser tab, including across page reloads; edits are not published yet.
- **Review and publish changes** shows changed records and fields before publishing them together.
- If someone else updates the selected data set while you are editing, publishing is paused. Compare the newer data with your saved edits, then either keep your draft or discard it and load the latest data. Re-enter any changes you still need.
- Data sets are selected independently per tab. A tab will not overwrite a newer version; reload or compare it before publishing.

Connection access is set up by an administrator. The advanced connection setup uses a GitHub access token; do not share that token.
